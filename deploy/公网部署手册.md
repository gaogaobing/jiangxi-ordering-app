# 江西小炒点餐系统 · 公网部署手册

> 目标：让顾客**走到哪都能扫码点餐**（不限于店里 WiFi）
> 方式：把系统放到公网上。两条路任选，推荐 **路线A**。

---

## 路线A：云服务器（推荐，稳定，约 50~100 元/年）

一台"永远在线的电脑"，你的点餐系统就住在里面，顾客随时扫码都能访问。

### A1. 买服务器（5分钟）
1. 打开 腾讯云 或 阿里云 官网 → 搜索「轻量应用服务器」
2. 选最低配即可：**2核2G**（或 2核1G），**系统选 Ubuntu 22.04**（或 CentOS 7）
3. 新人首购通常 50~100 元/年。买完会看到公网 IP（类似 `120.24.xx.xx`）

### A2. 上传项目（10分钟）
方法1（最简单）：**宝塔面板**
- 服务器购买页可一键装「宝塔面板」，装好后用浏览器打开面板地址
- 面板里「文件」→ 上传 `jiangxi-ordering-app.zip` → 解压

方法2（命令行）：Windows 自带的 PowerShell 即可
```powershell
scp 你的部署包.zip root@你的服务器IP:/root/
ssh root@你的服务器IP
```

### A3. 一键部署（5分钟）
```bash
cd /root/jiangxi-ordering   # 进入解压后的目录
chmod +x deploy/deploy.sh
sudo bash deploy/deploy.sh
```
脚本会自动：装 Node.js → 装依赖 → 启动服务 → 开机自启（服务器重启也不用管）。

### A4. 放行端口（重要！）
登录云厂商控制台 → 找到这台服务器 → 「防火墙 / 安全组」
→ **添加入方向规则：TCP 端口 3000，允许所有来源（0.0.0.0/0）**

### A5. 验证
手机流量（别连 WiFi）打开：`http://你的服务器IP:3000` ✅ 能打开就成功了

### A6. 绑定域名（可选，强烈推荐）
- 买一个域名（如 `diancan.xxx.com`，约 10~30 元/年），或直接用免费域名
- 云厂商控制台 → DNS 解析 → 添加 A 记录指向服务器 IP
- 配 HTTPS 证书（腾讯云/阿里云免费证书），这样地址栏有小锁 🔒 顾客更放心
- 我提供的 `nginx.conf` 已经写好反向代理配置，装上 nginx 改个域名即可用

### A7. 生成新桌码
- 桌码生成器地址填：`http://你的域名:3000`（或 `https://你的域名`）
- 重新生成 → 打印 → 贴桌

## 路线B：内网穿透（零成本，当天能用）

原理：装一个小软件，把店里电脑的 3000 端口"捅"到公网，得到一个公网地址。
**要求：店里电脑保持开机 + 不关机。**

推荐 **cpolar**（免费版够用）：

1. 到 cpolar.com 注册账号（免费）→ 下载 Windows 版
2. 安装后登录，命令行执行：
   ```
   cpolar http 3000
   ```
3. 完成！屏幕上会出现一个公网地址，类似：
   `https://xxxxx.cpolar.top`
4. 把这个地址填进桌码生成器 → 生成 → 打印贴桌

其他同类工具：花生壳（oray.com）、ngrok。原理一样。

⚠️ 免费版缺点：地址会变（每次重启软件变一次），域名带后缀不够专业。
但作为**验证阶段**完全够用。

## 两条路怎么选

| 对比 | 路线A 云服务器 | 路线B 内网穿透 |
|------|--------------|--------------|
| 成本 | 50~100元/年 | 免费（专业版才收费） |
| 稳定 | ✅ 7x24 稳定 | 电脑关机就断 |
| 地址 | 可以有自己的域名 | 免费版地址会变 |
| 适合 | **正式营业用** | 先测试、零成本起步 |

## 常见问题

**Q: 电脑上就能用，为什么要服务器？**
A: 电脑关机、断网、店里 WiFi 限速都会导致点餐系统失效。服务器 7x24 在线，顾客随时能点。

**Q: 服务器上的数据和我店里的数据同步吗？**
A: 不自动同步。建议：先在本地把菜品、图片配置好，上传部署包时一起带走（部署包含 `data/db.json` 和 `public/uploads/` 图片）。

**Q: 换电脑/服务器了怎么办？**
A: 把 `data/` 目录和 `public/uploads/` 目录打包带走，新环境解压覆盖即可，菜品订单全都在。

**Q: 管理后台密码怎么改？**
A: 打开服务器上的 `data/db.json`，找到 `adminPassword` 字段改成新密码，重启服务生效。

**Q: 部署过程报错了？**
A: 把报错信息截图，发给我（WorkBuddy），我帮你解决。或者执行 `journalctl -u jiangxi-ordering -n 50` 查看日志。
