🌶️ 江西小炒点餐系统

公网部署手册（云服务器版）· 跟着做，约 30 分钟上线

1买服务器（5分钟）

  1. 打开 腾讯云 或 阿里云 官网 → 搜索「轻量应用服务器」
  2. 选最低配：2核2G，系统选 Ubuntu 22.04（或 CentOS 7）
  3. 新人首购通常 50~100 元/年，买完会看到公网 IP（类似 120.24.xx.xx）
  4. 记住：服务器IP + 登录密码（购买页设置）
💡 不会选就买「腾讯云轻量应用服务器 2核2G，Ubuntu 22.04」最低配即可，这个系统跑点餐系统绰绰有余。

2上传部署包（10分钟）

推荐方法（图形界面，最简单）：在云服务器控制台找到「宝塔面板」或「文件管理」

  1. 服务器购买页/控制台可一键安装「宝塔面板」，装好后浏览器打开面板地址
  2. 面板「文件」→ 上传 jiangxi-ordering-app.zip → 解压到 /root/ 下
  3. 得到目录 /root/jiangxi-ordering/

或者用命令行（Windows 自带 PowerShell）：

scp jiangxi-ordering-app.zip root@你的服务器IP:/root/
ssh root@你的服务器IP
cd /root
unzip jiangxi-ordering-app.zip

3一键部署（5分钟）

在服务器上执行（自动装 Node.js → 装依赖 → 启动 → 开机自启）：

cd /root/jiangxi-ordering
chmod +x deploy/deploy.sh
sudo bash deploy/deploy.sh
✅ 看到「部署成功」就完成了。服务已开机自启，服务器重启也不用管。

4放行端口（重要！）

登录云厂商控制台 → 找到这台服务器 → 「防火墙」或「安全组」

  • 点击「添加规则」
  • 协议：TCP，端口：3000，来源：0.0.0.0/0（所有来源）
  • 保存
⚠️ 这步不做，外面就访问不到！80% 的部署失败都是因为这步漏了。

5验证 + 换桌码

用手机流量（不要连 WiFi）打开：

http://你的服务器IP:3000
✅ 能打开点餐页面 = 公网部署成功！

重新生成桌码

  1. 打开桌码生成器：http://你的服务器IP:3000/qr-tables.html
  2. 点「📡 检测IP」→ 手动改成 http://你的服务器IP:3000（或域名）
  3. 填桌号范围 → 生成 → 打印 → 贴桌
💡 以后顾客走流量、在店外都能扫码点餐，不再限制店里 WiFi。

6绑定域名（可选，强烈推荐）

  1. 买一个域名（如 diancan.你的店名.com，10~30 元/年）
  2. 云厂商控制台 → DNS 解析 → 添加 A 记录 → 指向服务器 IP
  3. 申请免费 HTTPS 证书（腾讯云/阿里云都有），地址栏出现小锁 🔒 顾客更放心
  4. 部署包里的 nginx.conf 已写好反向代理，装上 nginx 改个域名即可
💡 域名不是必须的，先用 IP 跑起来，以后生意好了再上域名。

❓ 常见问题

Q：部署过程报错怎么办？

把报错截图发给我（WorkBuddy），我帮你解决。或者看日志：journalctl -u jiangxi-ordering -n 50

Q：管理后台密码怎么改？

打开服务器上的 data/db.json，找到 adminPassword 改掉，重启服务生效。

Q：店里的菜品数据怎么带过去？

部署包里已经包含了 data/db.json（菜品+订单）和 public/uploads/（菜品图片），直接用部署包部署即可。如果之后又在本地改过，重新打包上传覆盖这两个目录。

Q：一个服务器能跑几个这样的系统？

2核2G 跑 5~10 个都没问题，放心。
